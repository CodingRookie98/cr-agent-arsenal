# 浏览器验证协议 (Browser Verification Protocol)

> 定位：定义「怎么验、证据长什么样、什么时候结论无效」。断言清单见 [acceptance-matrix.md](acceptance-matrix.md)。

---

## 1. 能力门控与执行路径 (Capability Gating)

| 能力 | 探测方式 | 有 | 无 |
|---|---|---|---|
| 浏览器驱动（截图/点击/输入） | 尝试打开目标 URL 并截取首屏 | 走真实产物断言 | 该域全部断言记「未验证」，列入阻断清单 |
| 键盘仿真 | 能否发送 Tab/Enter/Esc 并读取焦点元素 | 执行键盘路径与焦点顺序断言 | 改人工待办，不得推断通过 |
| 屏幕阅读器 | 宿主是否提供读屏输出 | 执行关键流程读屏断言 | 记未验证；自动扫描不得替代 |
| 性能测量 | 能否读取构建体积与交互时序 | 执行性能预算对比 | 记未验证；禁止用主观流畅度替代 |

**降级纪律**：与 `taste-driven-designer` 的 Critic 降级评审不同，本技能**没有降级通过路径**——产物验收的判据必须是真实运行证据。能力缺失时唯一合法输出是「未验证 + BLOCKED」。

---

## 2. 证据契约 (Evidence Contract)

每条断言必须记录以下字段，缺一即视为该断言无效（不计入通过数）：

| 字段 | 层级 | 要求 |
|---|---|---|
| 断言 ID | 行级 | 对应 acceptance-matrix 中的编号（如 S4 / V1 / A3 / B2 / P1） |
| 操作步骤 | 行级 | 可被第二人独立复现的最小步骤序列 |
| 观察结果 | 行级 | 实际观察到的现象（失败时须写原始错误文本；成功时可写「符合预期」） |
| 状态 | 行级 | 已实现 / 已实现未验证 / 已运行验证 / 未验证（必须显式标注，缺失即该断言无效） |
| 证据引用 | 行级 | 相对路径（截图 / 日志 / 测量输出），文件必须真实存在 |
| 环境 | 报告级 | 报告头部记录 URL、构建号或 commit、浏览器与版本、视口尺寸、网络档位；行级可按需覆盖 |

> 行级字段对应《前端验收报告》明细行的「操作 / 证据 / 状态」三项；报告级字段见模板头部（轮次标识）与第 1 章（验收范围）。

**反伪造要求**：
- 证据文件必须由本轮操作产生，不得复用历史轮次的截图充当本轮证据；
- 报告需记录**本轮捕获时间戳**与**产物构建号/commit**，二者与证据文件不一致时该断言无效；
- 空白、未加载、明显错位的截图不得作为通过证据（这是「空白产物」作废规则的产物级对应）。

---

## 3. 轮次回执与作废规则 (Receipt & Invalidation)

1. 每轮验收生成**轮次 nonce** 与**构建号/commit**，写入报告头部；
2. 若本轮使用了独立审查者（例如派发子智能体复核产物证据），其输出必须以 `Receipt: <nonce>` 开头，且回执的构建号必须与报告一致；
3. 以下情况该轮**作废**：回执缺失或不匹配、证据为空白/明显未加载、产物构建号与证据不符、操作步骤不可复现；
4. **作废二级上限**：连续 **2 轮**作废 → 停止循环，排查产物管线（构建/截图/回执链路）并升级人工；作废不计入有效轮次，但连续作废即故障信号；
5. 报告单列**作废计数**与作废原因。

---

## 4. 结论语义 (Verdict Semantics)

| 结论 | 条件 | 后续动作 |
|---|---|---|
| **PASS** | 五域断言全部通过，且无未验证项 | 交人类签收；需要代码级确认时再转 `dual-round-review` |
| **FAIL** | 存在失败断言，且无未验证项 | 按 [regression-routing.md](regression-routing.md) 分流修复后重验受影响断言 |
| **BLOCKED** | 存在任何未验证项（含能力缺失） | 不得宣称交付完成；列出未验证清单与所需能力，交人类裁决 |

**禁止**：用「大部分通过」「基本可用」「不影响主流程」等自然语言总结替代断言表与三态标注；禁止输出任何分数或通过率作为结论。

---

## 5. 报告与门禁绑定

- 报告结构由 `scripts/check-qa-report.sh` 机械校验（必需区块 / 三态齐备 / 明细断言数与结论表声明一致）；
- 结构校验不通过的报告不得进入人工签收环节；
- 签收区必须由人类填写；智能体只能填写「建议结论」并保留证据链。
