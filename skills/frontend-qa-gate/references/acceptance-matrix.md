# 五域验收矩阵 (Acceptance Matrix)

> **验收基线来源（A 方案）**：本清单是 `taste-driven-designer` Gate A 扩展项的**内联最小可执行副本**（共 31 条断言），来源版本为 taste 的 SKILL.md 铁律 3 与 `references/critic-loop-protocol.md` Gate A（V1.2 补强，2026-09-21）。
> **漂移触发条件**：本清单与 taste Gate A 出现 2 次及以上不一致时，按 A 方案迁移到共享基线文档（B 方案）并登记。

> 定位：本文件是 `frontend-qa-gate` 的可执行断言清单。每条断言都必须二值可判定（PASS / FAIL），
> 并附**操作步骤 + 证据路径 + 三态标记**。无法二值判定的内容不得进入清单。

> **边界**：本清单只覆盖**运行中的产物行为**。代码级正确性判据（hydration 静态推理、类型逃逸、
> 依赖边界、竞态实现缺陷）**不在本技能**范围内，归 `dual-round-review` 的审查维度与失败模式库；
> 设计品味与方向裁决归 `taste-driven-designer` 的 Critic 与 **Gate C 人类签收**。本技能不签发设计放行。

## 1. 状态矩阵 (State Matrix · D-S 交互状态断言)

**填写纪律**：对每个受检查单元（页面 / 组件 / 流程节点）逐格填写九态，**缺失态写「未实现」，不得留空**。

| # | 断言 | 操作步骤 | 证据 |
|---|---|---|---|
| S1 | 初始态渲染完整，无内容跳动（CLS 可见范围内无位移） | 冷加载页面，录制首屏 | 录屏或前后帧截图 |
| S2 | 加载态真实存在且可感知（判定口径：限速下加载指示持续可见 ≥300ms；人工判定项） | 限速 Slow 3G 打开，观察首屏到就绪 | 限速截图 |
| S3 | 空态有明确说明与下一步指引，而非空白或报错 | 清空数据/使用新账号打开列表 | 空态截图 |
| S4 | 错误态提供原因与重试入口，且**保留用户输入** | DevTools 断网后提交表单 | 错误态截图 + 输入内容截图 |
| S5 | 禁用态语义可见（视觉 + `disabled`/`aria-disabled`） | 未填必填项时检查提交按钮 | 截图 + DOM 属性记录 |
| S6 | 键盘焦点可见且顺序符合视觉顺序 | 仅用 Tab 走完主流程，记录焦点轨迹 | 焦点轨迹日志 + 截图 |
| S7 | 重复提交被阻止或幂等（二次点击不产生重复副作用） | 快速双击提交 / 重复提交同一请求 | 网络面板请求计数 |
| S8 | 返回恢复不丢状态（浏览器后退或路由返回） | 填写到一半后退再前进 | 前后截图对比 |
| S9 | 派生状态可从既有数据推导（判定口径：变更数据后派生显示随之更新，且无额外 Effect 副本；人工判定项） | 变更数据后观察派生显示 | 行为观察记录 |

## 2. 视口矩阵 (Viewport Matrix · D-R 响应式断言，本节共 8 条断言)

**填写纪律**：判据是**内容连续适配**，不是断点数量。至少覆盖：最小目标宽度、主流移动端、平板、桌面。

| # | 断言 | 操作步骤 | 证据 |
|---|---|---|---|
| V1 | 最小目标宽度（如 320/375）无横向滚动条 | 设为 320px 宽，滚动到底 | 截图 + 滚动条检测 |
| V2 | 无元素溢出父容器或互相遮挡 | 逐区段目检 + `scrollWidth > clientWidth` 检测 | 检测输出 + 截图 |
| V3 | 长文本、超长单词、长列表标题不撑破布局 | 注入长文本/长标题 | 注入后截图 |
| V4 | 移动端软键盘弹出不遮挡关键输入与提交按钮 | 真机或模拟软键盘聚焦输入框 | 截图 |
| V5 | 刘海屏安全区域生效（内容不被挖孔/圆角遮挡） | 安全区设备或模拟器 | 截图 |
| V6 | 横屏与竖屏切换后布局仍可用 | 旋转设备 | 双方向截图 |
| V7 | 触控目标不小于约 44x44 CSS px，且相邻目标不误触 | 测量关键按钮尺寸 | 尺寸测量记录 |
| V8 | 用户缩放（放大到 200%）不丢失内容或功能 | 系统级缩放或浏览器缩放 | 缩放后截图 |

## 3. 可访问性基线 (A11y Baseline · D-A 无障碍断言，本节共 8 条断言)

**纪律**：自动扫描结果**不构成**无障碍验收结论，必须叠加人工实测（键盘 / 焦点 / 读屏）。
**豁免例外**：装饰性、纯排版占位且对流程无影响的图像，可在报告中登记豁免并说明理由。

| # | 断言 | 操作步骤 | 证据 |
|---|---|---|---|
| A1 | 所有输入控件有关联标签，或 `aria-label` / `aria-labelledby` | 自动扫描 + 人工抽查表单 | 扫描输出 + DOM 记录 |
| A2 | 图标按钮有可访问名称（如 `aria-label`） | 自动扫描 + 抽查工具栏 | 扫描输出 |
| A3 | 任何功能均可仅用键盘完成 | 仅键盘走完关键流程（含弹窗与菜单） | 键盘操作日志 |
| A4 | 焦点顺序合理、焦点可见、弹窗内焦点不逃逸 | Tab 遍历 + 打开弹窗后 Tab 一圈 | 焦点轨迹 + 截图 |
| A5 | 关键流程通过读屏可用（可被朗读与操作） | 屏幕阅读器走主干流程 | 读屏记录 |
| A6 | 尊重 `prefers-reduced-motion`（动效降级） | 打开系统减少动态效果后观察 | 前后对比截图/录屏 |
| A7 | 语义结构正确（标题层级、landmark、列表语义） | 语义树或无障碍树检查 | 语义树输出 |
| A8 | 状态变化可被感知（如提交结果、错误提示） | 读屏或 `aria-live` 记录结果区 | 记录输出 |

## 4. 浏览器矩阵 (Browser Matrix · D-B 浏览器覆盖断言，本节共 3 条断言)

| # | 断言 | 操作步骤 | 证据 |
|---|---|---|---|
| B1 | 目标浏览器**最低支持版本**已记录并在其上验证关键流程 | 按记录版本真机或容器验证 | 版本号 + 截图 |
| B2 | 关键流程在浏览器矩阵（Safari / Chrome / Firefox / WebView 中目标项）逐项通过 | 逐浏览器走主干流程 | 各浏览器截图 |
| B3 | 新 CSS/JS 能力有特性检测或回退，不依赖单一浏览器实现 | 代码与运行时能力核对 | 能力检测输出 |

## 5. 性能预算 (Performance Budget · D-P 性能断言，本节共 3 条断言)

| # | 断言 | 操作步骤 | 证据 |
|---|---|---|---|
| P1 | 构建产物体积相对基线无未解释增长（判定口径：任何增长须逐项给出原因，无原因即 FAIL） | 对比改动前后构建输出 | 构建体积对比表 |
| P2 | 关键交互延迟（如首屏可交互、提交反馈）相对基线未回归 | 代表性设备与网络下各测多次取分位 | 测量数值 |
| P3 | 图片与媒体加载策略合理（判定口径：非首屏图片必须有懒加载或显式尺寸声明；人工判定项） | 网络面板核对资源与策略 | 网络面板导出 |

## 6. 断言总数与填写要求

- 五域共 **31 条断言**（状态 9 · 视口 8 · 无障碍 8 · 浏览器 3 · 性能 3）；
- 未触及的域仍必须填写结论，缺失能力按「未验证」记录；
- 每条断言的记录字段（操作 / 证据 / 三态 / 环境）见 [browser-verification-protocol.md](browser-verification-protocol.md) §2。

## 7. 与其它技能的分工（防重复）

| 问题类型 | 归属 |
|---|---|
| 产物在真实浏览器中的行为（本文件全部断言） | `frontend-qa-gate` |
| 代码正确性、hydration 推理、类型与依赖边界、竞态实现 | `dual-round-review`（含其失败模式库） |
| 设计方向、视觉品味、盲比改进与 Gate C 签收 | `taste-driven-designer` |
| 安全与供应链（XSS / 密钥 / 依赖投毒） | 宿主 CI 与权限层（本技能只报告与升级） |
