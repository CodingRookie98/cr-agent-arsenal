# 三项收敛自检：执行规程 (Convergence Checklist)

> **定位**：本文件展开 [SKILL.md](../SKILL.md) §4「提问收敛律与三项收敛自检」，**不新增政策**。
> **一句话**：自检不带新问题，只回答三项；三项皆否定且都有台账证据，才算收敛。

## 1. 时机与形式

- 每个里程碑（默认：每轮提问结束）执行一次；不额外增设里程碑。
- 自检回合**不带新问题**；自检中发现的疑问只能进入下一轮，不得混进本轮结论。
- 自检前先确认台账结构齐备：三类登记都有内容（字段纪律见 [references/decision-ledger.md](./decision-ledger.md)，机械校验用 `python3 scripts/check-decision-ledger.py <台账文件>`；POSIX 下旧 `.sh` 兼容壳仍可用）。
- 结论落进需求确认文档的「收敛结论」段（骨架见 [templates/requirement-confirmation-template.md](../templates/requirement-confirmation-template.md)）。

## 2. 逐问判定标准

### Q1 核心业务目标与流程是否仍有未明确？

判定问法：把已决项台账反读一遍，能否写出完整主干——**谁 / 在什么触发下 / 走哪些步骤 / 得到什么结果**？

判「是」（即未明确）的典型情形：

- 主干任一环节写不出，或只能靠「大概」「通常」补全；
- 触发条件或结果定义含糊，成功标准不可判定；
- 已决项对同一环节给出两种取值。

证据要求：主干每一步都能指向 D-NN 或 A-NN；不能指向的步骤即为未明确。

### Q2 关键边界与异常情况是否仍有未确认？

候选清单（按任务裁剪，不必全取）：失败与重试、空态与首次运行、并发与重复提交、权限与越权、超时与取消、回滚与补偿、幂等、规模上限与配额、外部依赖不可用。

判定问法：候选中每一项，要么有 D- / E- / A- 登记，要么被显式判定为「不适用」并写明理由。

判「是」的情形：存在既无登记、又无「不适用」理由的候选边界。
**注意**：把边界判为「不适用」也是一种裁决，必须有理由；无理由的「不适用」等于漏项。

### Q3 已决项之间是否存在相互矛盾的描述？

判定问法：

1. 按影响面分组，两两比对同一决策面的 D-NN：出现两个不同取值 → 矛盾；
2. 术语表与正文用词是否一致（§1 术语先行）；同一概念两种叫法会让后续判断漂移；
3. A-NN 是否与 D-NN 冲突：默认假设不得覆盖已决项；冲突时二者必有一个失效，需重新裁决并更新台账。

判「是」的情形：任一比对出现不同取值。

## 3. 收敛判据

- **三项皆否定（无新增信息增量）即收敛**。收敛动作三件套：
  1. 闭合主干（Q1 的主干链完整）；
  2. 把剩余边界登记为**显式默认假设**（未登记不算）；
  3. 输出需求确认文档。
- **任一为是则继续**，且下一轮问题必须落在该项上，不得偏移到低影响细节。
- **不以穷尽问题为出口**：出口是「无新增信息增量」，不是「问题问完了」。

## 4. 「没问题了」不算收敛：反例与对照

| 不合格的自证（反例） | 为什么不合格 | 合格对照（台账证据） |
| :--- | :--- | :--- |
| 「没问题了」/「看起来清楚了」 | 主观印象，无证据；换一轮措辞就可能推翻 | Q1：主干 5 步分别指向 D-01…D-05；Q2：9 项候选边界全部有登记或理由；Q3：同影响面比对无冲突 |
| 「用户没再提异议」 | 沉默不等于确认；未登记的疑问仍在 | 列出用户已裁决项的出处（轮次 / 日期）；未裁决项一律登记为 A-NN |
| 「已经问了 N 轮，够了」 | 轮次预算不是收敛判据；预算耗尽的动作是升级裁决（§5），不是宣布收敛 | 预算触顶时升级：现状 / 已验证信息 / 当前瓶颈 / 待裁决分叉 |
| 「问题清单问完了」 | 清单穷尽 ≠ 目标明确；不以穷尽问题为出口 | 三项自检逐条否定，且否定理由能引用台账编号 |
| 「上次自检已经通过」 | 两个里程碑之间可能有新裁决、新假设进入 | 以当前台账为输入重新逐条核对，而不是沿用上次结论 |

## 5. 自检记录的写法

每条自检至少写：问题编号、答案（是 / 否）、引用的台账编号、否定理由。示例：

- Q1：否。主干「下单 → 支付 → 发货通知」逐步落在 D-02 / D-04 / D-05，无缺口。
- Q2：否。9 项候选边界：E-01 / E-02 已排除，A-03 / A-04 为默认假设，其余 5 项标注「不适用 + 理由（单租户，无并发写）」。
- Q3：否。同影响面比对 6 组无冲突；术语表「订单」与正文一致。
- 结论：收敛。剩余边界已登记为 A-03 / A-04，输出需求确认文档。
