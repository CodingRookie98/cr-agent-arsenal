# 决策台账：字段、去重与提前收敛 (Decision Ledger)

> **定位**：本文件展开 [SKILL.md](../SKILL.md) §3「决策台账」，**不新增政策**；规程本体与优先级以 SKILL.md 为准。
> **用途**：让 §4 的三项收敛自检有可核验的证据——台账里没有的，视为没定过。

## 1. 登记时机与位置

- **即时登记**：裁决落下或被采用的那一刻就写进计划文件或检查点；禁止事后补记，禁止只留在对话里（上下文压缩后对话不再是证据）。
- **位置**：计划文件的「决策台账」小节，或需求确认文档的对应小节；骨架可直接取用 [templates/decision-ledger-template.md](../templates/decision-ledger-template.md)。
- **可核验性**：每条登记都有编号（D- / E- / A-），§4 自检逐条引用编号而非复述印象；结构完整性可用 `bash scripts/check-decision-ledger.sh <文件>` 机械校验（退出码 0 / 1 / 2）。

## 2. 三类登记的「必须写明」字段

### 2.1 已决项（D-NN）

| 字段 | 必填 | 写法 |
| :--- | :--- | :--- |
| 编号 | 是 | `D-01` 起顺序编号，台账内唯一 |
| 结论本身 | 是 | 一句话、可执行、可判定；写结论不写过程（写「统一走服务端 API」，不写「讨论了持久化方案」） |
| **出处** | 是 | 用户裁决（第 N 轮 / 日期）或证据（文件:行、命令输出、权威规范链接）；不得写「常识」「惯例」「一般认为」 |
| 影响面 | 是 | 被该结论约束的模块、文件、接口或范围 |

> **出处为什么必填**：没有出处就无法区分「用户拍板」与「模型自拟」。自拟取值应当登记为默认假设（A-NN）；混入已决项会让未确认的假设获得已决的外观。

### 2.2 已排除边界（E-NN）

| 字段 | 必填 | 写法 |
| :--- | :--- | :--- |
| 编号 | 是 | `E-01` 起顺序编号 |
| 被排除的方案或范围 | 是 | 边界本身要有名字（「本期不做移动端原生客户端」），不写「移动端的问题」 |
| **排除依据** | 是 | 用户裁决 / 证据 / 预算约束三者之一；不得只写「不需要」「不合适」 |
| 复开条件 | 是 | 出现什么新证据才允许重开；默认写「无——除新证据外不得重开」，使去重判定有可执行入口 |

### 2.3 默认假设（A-NN）

| 字段 | 必填 | 写法 |
| :--- | :--- | :--- |
| 编号 | 是 | `A-01` 起顺序编号 |
| 取值 | 是 | 具体、可执行的值（「会话空闲过期 30 分钟」），不写「待定」「按需」 |
| **影响级别** | 是 | 低 / 中 / 高，判定口径见 §5 |
| 可否决性 | 是 | 用户是否可否决（是 / 否）；写「是」时说明推翻后由谁改 |
| 反转成本 | 是 | 被否决后需要改动的范围（文件 / 模块 / 接口数） |

## 3. 去重纪律：换说法重开即违规

判定式：**新问题的答案是否会改变已登记条目（D- / E- / A-）的取值？** 会 → 有新信息增量；不会、只是措辞不同 → 违规重开。

反例（违规）：

- 第 2 轮已登记 `E-02 不引入离线优先的本地缓存层`；第 4 轮问「弱网场景下要不要做本地缓存？」——同一决策面、同一依据、无新证据 = 换说法重开。
- 第 1 轮已登记 `D-03 鉴权用服务端会话`；第 3 轮问「登录态放 Cookie 还是 JWT？」——已被 D-03 覆盖的子问题 = 重复提问。
- 把「不做 X」改问「为什么不考虑 X」，也属重开：答案空间与 E 条目完全相同。

正例（允许）：

- 带着 E-02 未包含的**新外部证据**重开，并显式引用原编号：「E-02 的复开条件被触发（实测弱网请求占比 18%），是否改为引入缓存？」
- 问题落在全新决策面（此前无 D- / E- / A- 覆盖）。

违规处置：停止该问题 → 引用原登记编号与依据 → 除非补上新证据，否则按原登记执行。

## 4. 提前收敛：低影响分支转默认假设的判定式

SKILL.md §3 要求「提前收敛时必须登记被判定为低影响而转为默认假设的分支；未登记即视为未收敛」。可转默认假设的分支必须**同时**满足：

1. **非全局前置项**：不属于 §1 的术语与范围歧义（§1 豁免分级，必须问，禁止转默认假设）。
2. **依赖强度 LOW**：该分支的取值不被任何已决项或外部接口依赖，其它问题的答案不随它变化。
3. **影响级别低**（满足任一即可）：反转成本限于单点（改一个模块 / 文件 / 配置常量，不动已决项与对外接口）；或默认取值有安全失败模式（选错可观测、可回滚，不产生不可逆后果）。
4. **四要素齐备**：取值、影响级别、可否决性、反转成本都能写全。

不满足任一条 → 必须进入本轮问题清单，不得转默认假设。
**未登记即未收敛**：§4 自检时，任何在对话里被「默默决定了」的分支如果找不到 A-NN 编号，一律判为未收敛。

## 5. 影响级别判定口径

| 级别 | 判据 | 默认假设处置 |
| :--- | :--- | :--- |
| 低 | 反转只动一个局部实现点，不改变已决项与对外契约 | 允许转默认假设 |
| 中 | 反转影响多文件或需要重跑测试，但不改对外契约 | 倾向登记 A-NN 并显式提示用户可否决 |
| 高 | 反转改变对外契约、数据模型或已决项 | 不得转默认假设，必须提问 |

## 6. 与收敛自检的接口

- 自检（§4）逐项引用台账编号作为证据；「三项皆否定」必须能回答「查了哪些条目、为什么否定」。
- 执行规程见 [references/convergence-checklist.md](./convergence-checklist.md)；校验脚本见 [scripts/check-decision-ledger.sh](../scripts/check-decision-ledger.sh)。
