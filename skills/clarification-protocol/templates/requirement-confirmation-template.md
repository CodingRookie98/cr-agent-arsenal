## 7. 显式化思考留痕（§6）

约束 → 候选 → 取舍 → 结论，四步各一行：

- 约束：首版 6 周内交付；团队无移动端人力；在线率目标 ≥ 99%。
- 候选：移动端原生 / 响应式 Web / 桌面 Web + 后续适配。
- 取舍：响应式 Web 兼顾覆盖面与工期；原生客户端成本超预算；离线缓存与在线率目标冲突且收益小。
- 结论：D-01 桌面 Web 优先 + 响应式布局；E-01 排除原生客户端分支。
