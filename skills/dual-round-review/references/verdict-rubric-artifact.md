# 产物分级与终止条件 (Artifact Verdict Rubric)

适用 `Review Schema: artifact`。与代码模式的 [verdict-rubric.md](verdict-rubric.md) **并列**，不互相覆盖：
代码模式的判据建立在「可执行的代码契约」上，产物模式的判据建立在 [artifact-contract.md](artifact-contract.md)
冻结的**产物契约**上。

---

## 1. 四级裁决

| 级别 | 定义 | 准入（**必须全部满足**） | 处置 |
|---|---|---|---|
| 🔴 **P1 契约违背** | 与 Intent / Constraints 直接冲突；或可外部核验的事实性错误；或按 Evidence Bar 成立且会导致严重误用的不可执行 | ① 落点在契约范围内 ② Grounds 指向产物内**确切位置** ③ Warrant 显式写出且**未被反证据驳倒** ④ Impact 具体到 Audience 的行为后果 | 阻断，修复后按 Mode 再循环 |
| 🟡 **P2 削弱** | 不违背契约，但显著降低达成度：读者误解风险、论证缺环、与 Audience 不匹配 | 同 P1 的 ①②③，Impact 非致命 | 记入待办，准予放行 |
| ⚪ **Dismissed** | 无 Warrant / Warrant 被反证据驳倒 / 落在 Out of Scope / 纯风格偏好 / 未做 steelman 的稻草人 | — | 丢弃，须陈述客观驳回理由 |
| ⚖️ **Undecidable** | 争点是无客观判据的**价值取舍**（品味、取向、优先级排序） | 双方最强理由各自成立，且无法再分解出可核验的子命题 | **立即停止辩论**，交人类裁决，附双方最强理由与各自代价 |

**降级规则（机械闸，防"什么都往 P1 装"）**：
- 准入 ①②③④ 缺任意一条 → **至少降为 P2**；
- **缺 Warrant → 直接 Dismissed**，不得定级；
- 指控落在 Out of Scope 内 → 直接 Dismissed（对应代码模式的「历史代码越界」）；
- 被 R2 判定为「契约过宽 / 过窄」的契约本身，可作为 P1 缺陷登记。

---

## 2. 终止条件（替换代码模式的「阻断项清零」）

产物没有「零缺陷」这个客观终点，因此收敛判据整体更换：

1. **信息增量收敛**：某一轮不再产生**新的、带 Warrant 的可定级指控** → 即判定收敛。
   （与 `clarification-protocol` 技能的三项收敛自检同构：无新增信息增量即闭合。）
2. **自适应中断**：`artifact + light` = 1 轮 R1 + 主智能体按本表裁决；`artifact + full` = R1 → R2 各 1 轮；
   **最多 1 次 Delta**。禁止以「再辩一轮更保险」追加轮次。
3. **⚖️ 出口**：落入价值取舍的争点**禁止继续辩论**，直接按 §1 的 ⚖️ 行处置。
4. **成本红线**：R1 报告 ≤ **400 行**、R2 报告 ≤ **200 行**。超限即视为审查失控，须在报告中登记原因
   （本仓库 2026-10-10 事件的产物是 6 份报告共 216KB，该上限即为其机械防线）。

---

## 3. 裁决明细表列定义（artifact 口径）

R2（或 Light 模式的裁决者）输出的 `## 2. 最终裁决明细表` 沿用既有 7 列结构，**列语义按本表**：

| 列 | artifact 口径的取值 |
|---|---|
| 稳定 ID (沿用 R1) | `R1-<n>`（命名空间与代码模式相同，勿改为其它前缀——门禁按 `R1-[0-9]+` 提取） |
| 检查点 / 位置 | 产物内确切位置（章节号 / 段落 / 引文片段） |
| 原始 R1 评级 | R1 给出的级别 |
| **归属** | `契约内` / `契约外`（对应代码模式的「本次引入 / 历史既有」） |
| 终审裁决 | 🔴 P1 / 🟡 P2 / ⚪ Dismissed / ⚖️ Undecidable |
| 最终定性分析与裁决理由 | 必须含：Warrant 是否成立、反证据（若驳回） |
| 处置要求 | 修复 / 记入待办 / 丢弃 / 交人类裁决 |

---

## 4. 交付判定

- 🔴 **阻断交付**：P1 > 0；
- ✅ **准予交付**：P1 = 0；
- ⚖️ **不可判定**：不得由审查者自行裁决，须交人类；**不得**把 ⚖️ 项计入 P1 以自动阻断，
  也**不得**把它静默降级为 P2 以自动放行——两者都属违规。
