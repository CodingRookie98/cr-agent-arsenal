# D2 Define — Critic 闭环与能力门控协议

> 实现者无法客观自审；批评须来自全新上下文、只看产物的独立 Critic。
> **V1.1 依据**：反证（[../tests/fixtures/critic-gate-counter-evidence.md](../tests/fixtures/critic-gate-counter-evidence.md) E1–E7）证伪打分门禁，严禁以分数作判据。

## 1. 三信号收敛门禁

D2 完成须同时满足三项，缺一不得入 D3 或交付：

- **Gate A · 视觉结构清单**：10 项 AI Tells 过审（[ai-tells-audit.md](ai-tells-audit.md)）+ 黑名单清零 + 层级/间距/配色克制/核心交互视觉态（hover/focus/disabled/空态/错误态）+ 契合 `Persuade`/`Operate`。*完整五域运行时验收由 `` `frontend-qa-gate` `` 独立承担，不复制矩阵。*
- **Gate B · 盲比改进 / 4+1 排序**：
  - **盲比 A/B**：上一版与当前版左右随机且**去标识**（文件名/水印/版本号），强制二选一，输出胜出维度、`Regressed dimensions` 与 `Top 3 to delete / simplify`。
  - **收敛语义**：`no material difference` 合法且计入「无改进」；全维无法区分即收敛交人类确认；`Regressed dimensions` 须清零或获接受。
  - **4+1 排序**：首版基线或破局时，4 张参考（锚点禁抄）+ 1 张自品随机同屏，输出 `1..5` 名次与距前一名差距。
  - **禁绝分数判据**：模板禁输出分数/等级；遥测须锚点图 + ≥2 名独立 Critic 中位数，只作注记且**永不入门禁**。
- **Gate C · 人类签收**：呈交 5 列评审表、Gate A 与仲裁结果，获创意总监签收。

## 2. 匿名、作废、鉴别力与仲裁

| 机制 | 触发条件 | 处置 |
|---|---|---|
| **盲比匿名性** | 派发盲比或降级 | 剥离文件名、注释理由、版本号与水印；仅传意图与已决原则 |
| **空白作废** | 截图空白或未加载 | 作废重采不入表；**连续 2 轮作废**停转升级人工 |
| **鉴别力自检** | 改动后输出逐字同 | Critic 失效：**停转**升级人工；同版结论矛盾换 Critic |
| **原则优先与防乒乓** | 冲突原则或同维反转 | 原则优先入表；同维反复反转冻结交人类裁决 |

## 3. 预算与 5 列评审表

- **5 轮硬上限**：先跑 1–2 轮验信号；D2 上限 **5 轮**；连续 **2 轮无改进**（含 `no material difference`）或达上限熔断汇报。
- **5 列评审记录表**（见 [design-brief-template.md](../templates/design-brief-template.md)）：`轮次 | 版本 | 模式 | 结论（胜出/回归/名次） | 采纳与否决`。

## 4. 无截图降级与多模态门控

| 能力 | 有能力时 | 缺能力时 |
|---|---|---|
| **截图** | 真截图盲比/排序（[critic-prompt-template.md](../templates/critic-prompt-template.md)） | **降级评审**：送脱敏语义树 + 视觉参数（hex/字体/间距/圆角）+ 关键区段，去标识；恢复后补审 |
| **生图** | 缺质感时生成资产并回浏览器目检（API Key 仅本地不入库） | 用 CSS 渐变、噪点纹理或 shader 替代 |
| **视频** | 纯底抠像循环或关键帧插值，控体积与降级帧（Key 仅本地） | 用 CSS transitions 或滚动驱动动效替代 |

## 5. D2 出口清单

- [ ] Gate A 全过；Gate B 改进或收敛且无未接受回归（`≤ 5` 轮）
- [ ] 无未决鉴别力/作废/原则冲突，获 Gate C 人类签收
