## 3. 红队攻击路径推演 (Concrete Failure Scenarios)
- **攻击路径 1: 未闭合 frontmatter 令托管索引「静默降级」为人工索引（新发现 DR1-13）**:
  - **触发条件**: 外部工具写入托管索引时被截断，或人为构造仅有起始 `---` 而无闭合 `---` 的索引（托管标记仍在 H1 之后）。
  - **复现推演**: 构造 `--- / title: damaged / # T / 空行 / 托管标记 / 空行 / 控制头+修订表+清单` 的 `quad/index.md`，执行 `register --root <tmp> --dir quad --file deployment.md`：`strip_leading_noise` 的闭合围栏搜索循环走到 EOF，`idx` 越过末行，`lines[idx:]` 为空串 → `is_managed` 返回 False → 走 `skipped-manual` 分支：rc=0、文件逐字节不变、stdout 打印「⚠️ 检测到人工索引（无托管标记）」——而标记实际存在于第 6 行。
  - **影响结果**: 自愈链静默失联且提示与事实相反（零写盘、零数据破坏，方向保守），排障者会把「判据失效」误读为「设计如此」；同一朴素围栏扫描对 YAML 块标量内的 `---` 也不做语义识别，实测可提前/滞后截断（两种落点均未造成误改写）。
  - **涉及代码**: `skills/doc-governance/scripts/manage-doc-index.py:78-89`（`strip_leading_noise`），调用点 `:99`；误判分支 `:208-210`、`:240-241`。
