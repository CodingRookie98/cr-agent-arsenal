## 3. 红队攻击路径推演

- **攻击路径 1: 单行行内代码触发「幽灵围栏」，彻底静默关闭 RFC-0007 状态机**
  - **触发条件**: 在任意受检 `.md` 文档头部或控制头之前存在以行首 3+ 反引号书写的行内代码（如 ```` ```inline``` ````），紧随其后为非法状态声明或违禁指针。
  - **复现推演**: `check-doc-health.py:48-50` 的 `_FENCE_RE = re.compile(r"^\s*(`{3,}|~{3,})")` 未校验反引号后的 info string 是否含反引号（对比同批修复的 `check-doc-links.py:35`）。行首 ```` ```inline``` ```` 被识别为开围栏，此后所有行均无法满足 `set(s) == {'`'}` 的闭合条件，导致整篇文档其余行被 `_unfenced_lines` 吞掉，`_parse_header_meta` 读到空字典后按隐式 `Active` 放行。
  - **影响结果**: 非法 `文档状态: Deprecated`、`Superseded` 缺指针或越界 `取代于: /etc/passwd` 全部逃逸，门禁返回 `rc=0` 绿灯。
  - **实测命令**:
    ~~~bash
    python3 -c 'import subprocess,sys,tempfile; from pathlib import Path
    with tempfile.TemporaryDirectory() as d:
        r = Path(d)/"docs"; r.mkdir()
        (r/"AGENTS.md").write_text("# R\n\n## 读取顺序\n1. a\n\n## 硬约束\n- b\n", encoding="utf-8")
        (r/"bad.md").write_text("# S\n\n\x60\x60\x60inline\x60\x60\x60\n\n> - **文档状态**: Deprecated\n> - **取代于**: /etc/passwd\n", encoding="utf-8")
        p = subprocess.run([sys.executable,"scripts/doc-gates/check-doc-health.py","--root",str(r)], capture_output=True, text=True)
        print(p.returncode, p.stdout.strip())'
    ~~~
    实测输出：`0 📊 状态统计: Active=1 Contested=0 Superseded=0 / ✅ 健康门禁通过: 0 项阻断, 0 项警告`。

- **攻击路径 2: 正文前 80 行引用块覆盖顶部 YAML 控制头，或控制头内说明引用块阻断表格扫描**
