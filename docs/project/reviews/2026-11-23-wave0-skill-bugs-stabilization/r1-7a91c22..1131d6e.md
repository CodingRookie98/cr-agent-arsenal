### 3.1 攻击路径推演

- **攻击路径 1：畸形含空白 Markdown 链接经拒检分支“空白漂白”绕过 `_is_safe_filename` 校验（R1-1）**:
  - **触发条件**: 台账「报告文件」列写入内部含 ASCII 空格、制表符 `\t` 或 Unicode 全角空白 `U+3000` 的损坏 Markdown 链接，例如 `[x](r1- aaa..bbb.md)`、`[x](r1-aaa..\tbbb.md)`、`[x](r1-aaa\u3000..bbb.md)`，或含无引号标题的 `[x](r1-aaa..bbb.md title)`。
  - **复现推演**:
    1. `_parse_report_filename()` L210 经 `_MD_LINK_RE` 匹配出 `target = "r1- aaa..bbb.md"`；
    2. L215 调用 `_is_safe_filename("r1- aaa..bbb.md")` 正确判定非法并返回 `False`；
    3. 代码落入 L217 拒检分支 `return "".join(target.split()) or "".join(cell.split())`——该分支本意是剥除 `\t` 避免破坏 `_ledger_rows()` 的制表符分隔协议、同时保留非法字符串交由 `_check_reports()` L425 显式拒绝；
    4. 由于 `target` 之所以非法**仅在于包含空白字符**，`"".join(target.split())` 将全部空白剥净，把非法目标反向清洗为合法文件名 `"r1-aaa..bbb.md"`；
    5. 下游 `_check_reports()` L425 对 `"r1-aaa..bbb.md"` 执行 `_is_safe_filename()` 返回 `True`，打开归档目录内真实存在的同名文件并通过校验。
  - **实跑取证**: 独立临时目录实测 `check-review-report.py` 对 `[x](r1- aaa..bbb.md)`、`[x](r1-aaa..\tbbb.md)`、`[x](r1-aaa\u3000..bbb.md)` 均返回 **`rc=0`（结构校验通过）**；对 `[x](r1-aaa..bbb.md title)` 误报为「报告文件不存在: `r1-aaa..bbb.mdtitle`」而非「路径非法」。
  - **边界澄清（未升级为 P1 的反证）**: 含 `/`、`\`、`..` 的任意逃逸组合（包括 `[x](../r1-aaa..bbb.md)`、`[x](. ./r1-aaa..bbb.md)`、`[x](. .)`、`[x]( )`）经 `"".join(target.split())` 后仍保留非法字符并被 L425 100% 拦截（`rc=1`，报「路径非法」），**不构成目录穿越或假报告绕过**，仅导致断裂 Markdown 链接被静默放行及错误分类。
  - **涉及代码**: `skills/dual-round-review/scripts/check-review-report.py:213-217`

- **攻击路径 2：非 Markdown 链接分支的路径分隔符静默剥离与加粗链接解析断裂（R1-2）**:
  - **触发条件**: 台账「报告文件」列写入裸路径 `/r1-aaa..bbb.md`、`\\r1-aaa..bbb.md`、`./r1-aaa..bbb.md`、`../r1-aaa..bbb.md`，或加粗包裹的 Markdown 链接 `**[r1-aaa..bbb.md](./r1-aaa..bbb.md)**`、label 含 `]` 的 `[R1 [v1]](./r1-aaa..bbb.md)`。
  - **复现推演**:

    2. 裸路径 `/r1-aaa..bbb.md` 与 `\\r1-aaa..bbb.md` 未命中 `_MD_LINK_RE`，跌回历史既有的 `_NON_FILE_CHARS_RE.sub` 逻辑把 `/`、`\` 静默剥除变成 `r1-aaa..bbb.md`（若同目录存在同名文件则 `rc=0` 放行），与 Markdown 链接分支 `[x](/r1-aaa..bbb.md)` 报「路径非法」形成语义不对称；而裸相对路径 `./r1-aaa..bbb.md` 则被误剥成 `.r1-aaa..bbb.md` 报错「文件不存在」。
