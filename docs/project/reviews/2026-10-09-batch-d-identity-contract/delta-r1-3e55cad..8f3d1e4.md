## 1. 第一性原理与本质溯源分析

- **改动性质定性**: **两处真根因修复（R1-4 读闸门、R1-5 地图半边）+ 一处单分支正确的处方补丁（R1-2）+ 一处无断言的文案订正（R1-1）+ 一次确实承重的回归网重建（R1-3）**。
  - R1-4 命中真实物理事实：`exists()` 对 FIFO / 字符设备 / 目录为真，其后 `read_text()` 直接进入无界读取面；`is_file()` 是该事实的最小充分判据。独立实测：审计对 FIFO 0.12s、字符设备软链 0.11s、目录 0.07s 均 rc=1 且给出可读缺陷串、无 traceback；把闸门变异删除后，同输入 FIFO 8.69s 挂死、字符设备 8.11s 无界读取未返回——闸门是承重件，不是装饰。
  - R1-5 也命中真实根因：旧码 `write_text` 的 open('w') 先创建、后编码；非法 UTF-8 文件名经 surrogateescape 进入 `rel_link` 后编码失败，磁盘留下 0 字节地图，随后生成器永久 fail-closed、审计报告被截断。旧码实测：0 字节地图 + 复跑 rc=1「既有地图无法安全读取」；新码实测：地图不存在 / 既有地图 56 字节逐字节不变 / 修名后 rc=0 且 `.tmp` 残 file 被下一次 replace 消费。**0 字节地图楔死确已根治**。
  - 但 R1-5 只消灭了「半成品地图」，没有消灭「失败路径」：编码失败仍以裸 traceback 收场（rc=1），并在 docs/ 留下 0 字节 `llms.txt.tmp`。更关键的是，**实际写入目标是一个全新路径，它完全落在两道归档写保护之外**（`main()` 只对 `out_path` 判定 `is_archive_path` / `in_evidence_archive`，`tmp_path` 未过闸）——这是 R1-21 的本质：修复动作引入了未被既有不变量覆盖的新写入面。

- **物理与业务一致性**: 契约链条在**读**侧已完整（审计与生成器逐字同源的反解语义、非规则文件闸门对称）；**写**侧的原子替换则出现了一条「影子路径」（`X.tmp`），它与 GOVERNANCE §4.1 承诺的「任何 `--root` 形态下都不写入交付凭据」（GOVERNANCE.md:116）不相容。另一处不一致发生在处方层：GOVERNANCE.md:97 规定地图必须是注册命令的逐字节产物，GOVERNANCE.md:124 规定注册命令沿用既有身份——分支 2 的文案（「请勿直接重新生成」+「先移除」）恰好把用户从这条唯一正确通道上劝离。

  - **触发条件**: `docs/llms.txt` 首行是**合法** H1，但其项目名不可安全回显（为空、含不可打印字符如 U+0007、超长 > 64、或 NBSP / ZWSP 等 `isprintable()` 为假），且正文与生成物漂移。
