## 1. 背景与问题陈述
judge.py 与 collect-facts.py 的输出路径仅校验 parent.is_dir()，随后 mkdir(parents=True, exist_ok=True) + write_text → 指向 contexts/AGENTS.md、docs/index.md 等被跟踪文件时静默覆盖。需显式指定该路径，SKILL.md 全部示例均指向 /tmp，无自动路径落入仓内。
