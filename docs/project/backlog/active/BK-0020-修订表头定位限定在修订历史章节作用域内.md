## 1. 背景与问题陈述
manage-doc-index.py 的 insert_revision_row 在全文档范围搜索首个『| 版本号』表头；若托管索引在修订历史之前存在另一张首列同名的表格，修订行会被写入无关表格并撑坏列数，而工具仍返回 rc=0、控制头照升，随后 check-doc-control-sync.py rc=1。历史既有（该搜索行自 2583210 起未改动），按边界锁封顶 P2、不参与阻断。
